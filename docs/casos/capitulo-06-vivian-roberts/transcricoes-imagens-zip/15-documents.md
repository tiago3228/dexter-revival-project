# Transcrição visual — documentos e cartas

Convenções: texto transcrito na ordem visual aproximada. Os textos impressos em português e os manuscritos ingleses sobrepostos são camadas distintas; quando a camada manuscrita está parcial ou encoberta, isso é indicado sem completá-la pelo contexto. Textos da sidebar são interface, não parte do documento. “CADERNO”, “CARTA/DOCUMENTO”, os itens de navegação, a barra de rolagem e os controles visíveis aparecem como elementos de interface.
