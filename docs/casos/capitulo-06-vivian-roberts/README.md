## Regras de produção
1. Não alterar os arquivos do caso Painscreek existente para construir este capítulo.
2. Não apresentar como fato uma hipótese, uma fala lembrada ou um resumo não conferido.
3. Transcrições de diários, cartas, relatórios e gravações devem ser integrais quando a fonte permitir, com página de origem e marcação de trechos ilegíveis.
4. Toda pista deve indicar sua origem, local de descoberta, quem a produziu (se conhecido), data (se conhecida) e quais inferências ela sustenta ou não sustenta.
5. Não assumir que uma pista prova culpa apenas por ligar alguém à vítima ou ao local.
6. A interface do jogador não deve identificar previamente qual rota investigativa está ativa.
7. Preservar a solução original em uma rota e criar uma segunda rota alternativa com solução própria. Os detalhes finais das rotas só serão definidos após conferência do material-fonte.
8. Não declarar o caso pronto para lançamento antes de integrar o componente, validar as transcrições, testar as dependências e executar build/testes.

## Status das informações
Use estas etiquetas no dossiê:
- **CONFIRMADO NA FONTE:** conferido diretamente no PDF/documento original.
- **TRANSCRIÇÃO PENDENTE:** item conhecido, mas texto ainda não conferido integralmente.
- **RELATO / TESTEMUNHO:** afirmação atribuída a uma pessoa, não necessariamente verdadeira.
- **INFERÊNCIA:** interpretação que precisa citar os itens de suporte.
- **HIPÓTESE DE DESIGN:** elemento planejado para a rota alternativa, não pertencente à fonte original.
- **CONTRADIÇÃO EM ABERTO:** duas fontes ou registros parecem incompatíveis.
- **ILEGÍVEL / INCERTO:** leitura que não pode ser confirmada com segurança.
