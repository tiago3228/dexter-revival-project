# Imagens complementares de Painscreek

Este diretório contém os **116 PNGs originais** extraídos do ZIP fornecido para o projeto. Os nomes dos arquivos foram preservados.

A interface apresenta miniaturas WebP em `thumbnails/`; ao clicar em uma miniatura, o navegador abre o PNG original em outra aba. As imagens complementam — não substituem nem modificam — o catálogo textual de evidências.

## Grupos preservados

- Diários identificados por autor: Andrew Reed, Bernard Hopkins, Charles Roberts, Derrick Tyler, Dorothy Patterson, James Howard, Mary Martinez, Matthew Brooks, Scott Brooks, Steven Moss, Trisha Roberts, Vivian Roberts e Wanda Tyler.
- Recortes de jornal: `jornal1.png` a `jornal7.png`.
- Documentos: `doc1.png` a `doc16.png`.
- Outros: `outros1.png` a `outros7.png`.

A numeração e os nomes são os do arquivo recebido; a ordem do nome, por si só, não afirma correspondência com uma página específica do PDF.
